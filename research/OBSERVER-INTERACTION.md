# Moving the observer

4 October 2026, after publication of v2.1.0.

The final interactive work exposes the existing collection-alignment diagnostic.
It introduces no new material simulation and does not amend either locked
experiment. The material trajectories remain fixed; one shared comparison
translation is the visitor's only continuous intervention.

For each finer response F_h, coarse candidate C_j and the already measured
collection shift mu, use the complete 3,468-coordinate RMS squared distance:

    D_hj(alpha)^2 = a_hj - 2 alpha b_hj + alpha^2 c
    a_hj = mean((F_h - C_j)^2)
    b_hj = mean((F_h - C_j) mu)
    c = mean(mu^2)

The shared quadratic term cancels in candidate comparisons. Every possible
nearest-reader transition therefore belongs to the lower envelope of 24 affine
functions for each history. Save coefficients without display rounding, derive
all actual transition intervals on [0, 1], and verify against separate direct
vector norms at endpoints, intermediate values and both sides of transitions.

The near receiver at 96/192 supplies the six visible rows of the print. The
other eighteen histories remain represented in the total reading and a full
accessible table. All counts use all 24 candidates. A selected row's projection
onto its own/rival direction is exact for that pair; it is a drawing of one
comparison, not a replacement for the full nearest-candidate calculation.

The interaction should make one action legible: move a shared origin and watch
the recorded comparisons change. A restrained automatic passage may be started
explicitly, paused and scrubbed; it must stop when the page is hidden. Provide
keyboard range input, a direct reset, an exact-boundary tie display, a full text
table and an exported SVG carrying the original dataset identity and current
alpha. No sound is added to this geometric work.

A loading or data-validation failure leaves the original print and companion
available. Release only after direct-vector agreement, actual browser control
and export checks, narrow rendered inspection, and updated offline/recovery
verification. The already published v2.1.0 remains a complete preserved edition.
