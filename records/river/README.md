# A River Twice: frozen result reports

These are unchanged reports from the four finite time studies and two separate
verification receipts. They are kept outside the `artifacts/` runtime tree so
a fresh source checkout can run the reproduction commands without overwriting
published records.

The [complete scientific archive](https://github.com/bernietorfen/palimpsest/releases/download/a-river-twice-1/palimpsest-finite-time-studies-001.tar.gz)
also includes the numerical arrays, both operational runs, the frozen producing
sources, tests, protocols and original manifests. Extract it into an empty
`artifacts/` directory to restore its canonical `studies/` and `reviews/` paths.

Read the [reproduction guide](../../research/RIVER-REPRODUCTION.md) and each
study's stated assumptions before interpreting a report. These records concern
declared finite models and calculations; they are not experimental observations
of a physical quantum system.
